### Scene 1 — Corridor Opens

**Timing window:** `0.0s - 4.0s`

**Narration subtitle:**

> New York and Bengaluru light up and a great-circle arc connects them.

**On-screen elements:** Orthographic globe, two pulsing city beacons, one arc with a gradient stroke.

**Animation physics:** Arc draws over 1.6s while both beacons run a 2-cycle pulse; the globe rotates 8 degrees for parallax.

### Scene 2 — Live Rate

**Timing window:** `4.0s - 9.0s`

**Narration subtitle:**

> The mid-market ticker ticks up while the user watches.

**On-screen elements:** Rate display 1 USD = 83.2410 INR in mono, micro sparkline underneath.

**Animation physics:** Digit rolls use per-character translateY; sparkline redraws from a 40-point seeded series at 12fps.

### Scene 3 — Cost Stack

**Timing window:** `9.0s - 14.0s`

**Narration subtitle:**

> Spread and fee are peeled off, leaving the exact landing amount.

**On-screen elements:** Horizontal stacked bar: principal, spread, fee; three legend rows.

**Animation physics:** Bar segments grow left to right at 120ms offsets; legend values count against the same scene progress.

### Scene 4 — Credit Lands

**Timing window:** `14.0s - 18.0s`

**Narration subtitle:**

> The rupees land in the recipient account with a settlement stamp.

**On-screen elements:** Recipient card, INR counter, 'credited in 11 minutes' stamp.

**Animation physics:** Counter eases to the final amount; stamp scales 1.4 -> 1.0 with a 220ms spring and a slight rotation.

### Scene Hand-off Rules

- Each scene fades its predecessor out over the final 180 ms; there are no hard cuts.
- The caption line crossfades with a 200 ms opacity transition and a 20 ms upward drift.
- The step indicator text is `Step N of 4: <Scene Name>` and must update exactly at the boundary fraction.
- Scenes never overlap in the progress calculation; the active scene is the last one whose `start` is less than or equal to `progress`.

## 3. SVG Vector Blueprint

| Vector | Purpose | Construction |
| --- | --- | --- |
| **Globe** | Geography | Circle plus 6 arcs for latitude/longitude lines at 18% opacity |
| **City beacons** | Endpoints | Two concentric circles with an expanding halo animation |
| **Corridor arc** | Money path | Cubic bezier sampled to 60 points, gradient stroke from indigo to cyan |
| **Rate sparkline** | Market motion | 40-point polyline generated by a seeded random walk, no smoothing filter |
| **Cost stack bar** | Fee transparency | Three adjacent rounded rects with a shared 8px height and 2px gaps |

### SVG Implementation Notes

- Use a single `<svg viewBox>` per scene group with `preserveAspectRatio="xMidYMid meet"` so the artwork scales with the container.
- Keep all stroke widths under 2.5 px at design scale; heavier strokes read as illustration rather than product UI.
- Define gradients and filters once in a shared `<defs>` block; duplicating filter definitions causes measurable paint cost.
- Drive self-drawing lines with `pathLength` normalization (`path.setAttribute('pathLength', 1)`) so dash offsets are expressed in 0 to 1 units.

## 4. Animation Physics

- The rate sparkline updates at a capped 12fps to read as a live feed without looking noisy at 60fps.
- Cost segments never overlap; compute each segment width from cumulative percentages.
- Globe parallax is a 2px-per-degree translate capped at 16px total.
- The stamp uses overshoot plus rotation(-6deg) to feel physically pressed.

### Shared Timing Constants

```js
const EASE = {
  decel:  'cubic-bezier(0.16, 1, 0.3, 1)',   // Apple-style entry
  inout:  'cubic-bezier(0.65, 0, 0.35, 1)',  // symmetric transitions
  spring: { stiffness: 220, damping: 24 },   // damped settle
  // linear is reserved for ambient rotation and real-time countdowns only
};

const clamp01 = (n) => Math.min(1, Math.max(0, n));
const lerp = (a, b, t) => a + (b - a) * t;
const band = (p, start, end) => clamp01((p - start) / (end - start));
const easeOut = (t) => 1 - Math.pow(1 - t, 3);
const easeInOut = (t) => (t < 0.5 ? 4 * t * t * t : 1 - Math.pow(-2 * t + 2, 3) / 2);
const springOut = (t) => 1 - Math.exp(-6 * t) * Math.cos(9 * t);
```

Use `band(progress, start, end)` for every sub-animation. It is the reason scrubbing backward works.

## 6. Reference Data Model

Bind every number on screen to this object. Do not hard-code figures inside render functions.

```js
const FX = { sendUsd: 1000, rate: 83.241, spreadBps: 35, feeUsd: 4.99, receiveInr: 82535.74, corridor: 'USD to INR', rails: 'SWIFT gpi + local IMPS', eta: '11 min' };
```

### Data Rules

- All currency displays use `Intl.NumberFormat` with the correct locale and two decimals (or the correct precision for the asset).
- Counters use `font-variant-numeric: tabular-nums` so digits do not shift width mid-count.
- Any derived figure (totals, percentages, deltas) is computed from this object at load and asserted in a dev-only check.
